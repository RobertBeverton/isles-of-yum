# Character Voice Guide

Checks that named, recurring characters sound and behave like themselves,
story to story. This is different from `world-consistency-check`, which
checks *facts* about the world — this is about *voice*: how someone actually
talks, jokes, reacts, and moves through a scene.

Full detail for each character lives in `reference/character-traits.md` in
this skill folder — read it before writing or reviewing any scene with
dialogue. This file is the process; that file is the content.

## When drafting

Before writing dialogue for a character, check `reference/character-traits.md`
for their established patterns. Specifically:
- What's their attention/pacing style — do they focus for a long time, or in
  short bursts? Does this affect how their dialogue and stage directions
  should read (e.g. Felix needs something physical to do or fidget with,
  Alex can sit with a problem for longer beats).
- What's their emotional entry point into a new place or situation —
  reserved-then-warms-up, immediately in the thick of it, something else?
- Do they have a signature way of thinking or communicating (e.g. Alex
  naturally turns observations into riddles rather than stating them
  plainly) — use it, don't just have them explain things directly if a more
  character-true method exists.

## When reviewing

Read back every line of dialogue for a named character and check:
- Would this line sound out of place if you covered the speaker tag? If a
  Felix line reads like something only Alex would say (or vice versa), flag
  it.
- Has a character gone silent for a long stretch of the story with no job
  (see World Guide craft rule 3 — give every named character a job)?
- If a character does something surprising or out-of-pattern, is there an
  in-story reason, or does it read as an accident of drafting?

## Updating this skill

When a story reveals new, genuine character detail (not just a one-off
action, but something that seems true of the character going forward),
add it to `reference/character-traits.md` so future stories can draw on it.
Treat this file as a living document, the same way `docs/World_Guide.md` is
— it should only ever grow more accurate, not be rewritten from scratch.
