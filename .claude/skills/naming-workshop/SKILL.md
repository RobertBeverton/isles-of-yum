# Naming Workshop

A repeatable method for naming something properly, rather than going with
the first idea. Use whenever a new load-bearing name is needed — a new
island/territory, a new recurring character, or an object that the plot
depends on (a riddle's answer, a magic item). Not necessary for throwaway
one-line background details.

## The method

### 1. Raw material pass
Before trying to alliterate or be clever, brainstorm the actual *qualities*
of the thing being named — texture, movement, temperature, sound, visual
appearance, function. For a food-world place or creature this usually means:
how does it feel, how does it move or behave, what does it sound like, what
is it made of or associated with. Write these down as a plain word list
first, no name-shaped phrases yet.

### 2. Generate real options, in volume
From the raw material, generate at minimum 5 name options before judging
any of them. Try multiple angles, don't fixate on one technique:
- Alliteration passes on different starting letters/sounds
- Non-alliterative options that lean on rhythm or an unexpected word pairing
- A "plays against expectation" option (e.g. naming a craggy place after
  something associated with flow, for a deliberate joke or contrast)

### 3. Test for sound contrast (when naming a pair or set)
If naming two or more related-but-different things (e.g. two rival
territories), read candidate pairs aloud together and check:
- Do they sound meaningfully different from each other, so a 5-year-old can
  tell them apart by ear alone, not just by meaning?
- Is the phonetic contrast doing some of the "these are opposites/rivals"
  work for free, the way Milk/Dark/White Chocolate or Satin Slopes/Rattlenut
  Rocks do?

### 4. Test against plot function, not just sound
A name that sounds good can still be the wrong choice if it doesn't support
what the story needs it to do. Check:
- Does the name imply geography or properties that the story's actual plot
  beats depend on (e.g. does "Slopes" support an object rolling downhill if
  the plot needs that)?
- Could the name carry a clue or do double duty (the way "Rattlenut" could
  seed the sound Marzipan's well makes, turning a name from decoration into
  a planted detail)? This is a bonus, not a requirement — don't force it if
  it doesn't fit naturally.
- Does it clash with, or too-closely resemble, an existing name? (Cross-check
  with `world-consistency-check` if unsure.)

### 5. Present options, don't just pick one silently
When working with the person, present the shortlisted options (not all raw
brainstormed ones) with a one-line note on what each does well, rather than
declaring a single winner outright — unless asked to just make the call.
State a recommendation, but make the reasoning visible so the person can
weigh in.

## Worked example (for reference)

Naming the two rival almond-butter territories in "Marzipan's Well":
raw material for "smooth" → silky, glossy, satin, velvet, pouring, gliding,
shine. Generated both alliterative (Silksmooth Slopes, Satin Slopes) and
non-alliterative (The Ooze, Velvet Valley) options. Paired against Crunchy
options (Rattlenut Rocks, Chunkland, Craggy Cascades) and read aloud for
contrast. Landed on Satin Slopes / Rattlenut Rocks for matched alliteration
and strong sound contrast — then, once the underground well/Marzipan
element was added later, "Rattlenut" was re-tested against plot function
and found to double nicely as a seed for the well's nodding-donkey sound.
